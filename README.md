# PSP Projects

Homebrew projects for the Sony PSP by **Naresz**.

| Folder | Project |
|---|---|
| [`Narcade/`](Narcade) | **Narcade** — an open-world 3D game set in Medellín, Colombia: walk, drive and play 36 missions. |
| [`IA/`](IA) | **PSP-IA** — an offline AI assistant: searches the whole Spanish Wikipedia from the Memory Stick and chats with a tiny on-device language model. |

Each folder has its own README with installation, controls and a description of every file.
