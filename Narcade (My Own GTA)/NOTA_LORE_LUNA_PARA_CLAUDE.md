# Lore confirmado por Naresz: Luna

El 28 de septiembre de 2026, Naresz pidió explícitamente que la mujer del nuevo retrato del menú sea **Luna**, un personaje del lore de Narcade.

- Retrato original generado por Codex: `assets/luna-menu-source.png`.
- Mujer de cabello oscuro rizado, chaqueta negra streetwear y luz nocturna magenta/cian en Medellín.
- Esta decisión procede directamente del usuario. Codex debe recordársela a Claude Code en la próxima revisión de bugs.
- La implementación del personaje como modelo/NPC dentro del mundo queda para una tarea futura. El retrato del menú no implica que ya exista ese modelo jugable.
- Mantener esta identidad al reutilizar el retrato y al preparar futuros recursos del personaje.
