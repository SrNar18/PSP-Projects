# Narcade — an open-world 3D game for the PSP

**Narcade** is an original homebrew game for the Sony PSP, set in a stylised version of
Medellín, Colombia. You play Nico, walking, jogging, running and driving through a city
with traffic, traffic lights, a Metro line, a cable car and 36 story missions.

It runs on real hardware (tested on a **PSP E-1000 with CFW PRO 6.60**) and in the
PPSSPP emulator. Made by **Naresz**.

## Playing it

1. Copy `Narcade.iso` to `ms0:/ISO/` on the Memory Stick (use the *Inferno* ISO driver),
   **or** copy the `PSP/GAME/NARCADE` folder (with `EBOOT.PBP`) to `ms0:/PSP/GAME/`.
2. Ready-made builds of each version are in [`release/`](release).

### Controls

| On foot | In a car |
|---|---|
| Analog stick / D-pad: move (the camera follows) | X: accelerate |
| Hold X: jog · tap X repeatedly: sprint | Square: brake / reverse |
| Triangle: get in / out of a nearby car | Analog stick / D-pad left-right: steer (harder at high speed) |
| Square: jump / climb a park wall � R + Square: interact | L / R: change radio station |

Circle: messages · SELECT: camera distance · START: pause menu (map, save).
Progress is saved with the PSP's own save-data menu.

## Features

- Seven districts of Medellín laid out on a warped valley grid, with slopes, a river,
  bridges, an elevated Metro line with stations and a Metrocable.
- Lane-based civilian traffic with traffic lights; police chases.
- Hand-built 3D renderer on the PSP's GE: per-face day/night lighting, night lights,
  shadows, and a **city geometry cache** so the CPU does not rebuild the city every frame.
- 36 missions, mini-games, radio stations, collectibles and a native save system.
- Character poses for walking, jogging, sprinting, one-handed pistols and two-handed
  long guns; jump and park-wall climb animations.
- NPC health, impact effects, fleeing and death poses; assaults increase the wanted level.

Version 2.33 has been compiled for PSP and checked in PPSSPP and host regressions.
Its appearance and performance on physical PSP hardware still need a playtest.

## Folder layout

| Path | What it is |
|---|---|
| `src/game.c` | Game logic: player controller, camera, cars, traffic, missions, HUD, audio mixing. |
| `src/render3d.c` | 3D renderer for the PSP GE (clipping, lighting, cars, people, city cache). |
| `src/city26.inc`, `src/city3d.inc` | Procedural city: blocks, buildings, streets, river, Metro. |
| `src/citymap.h`, `src/world_geo.h` | City map (parcels, collision) and the valley projection / terrain height. |
| `src/daylight.inc` | Day/night cycle, sun lighting, glow and shadow effects. |
| `src/story.h` | Mission data (generated by `tools/story.py`). |
| `src/psp_main.c` | PSP entry point: main loop, frame pacing, save dialogs, input recorder. |
| `assets/` | Textures, title screens, audio and 3D models used by the build. |
| `tools/` | Build scripts (`build_windows.py`, `package_iso.py`), asset generators and `qa_*.c` test harnesses. |
| `release/` | Packaged builds of each version (`Narcade_vX.YY`), with notes and checksums. |
| `NOTAS_CLAUDE_PARA_CODEX.md` | Detailed development log (Spanish) for the people/AIs working on the code. |
| `COMPILAR.md` | Build instructions (Spanish). |

## Building

With [PSPDEV](https://pspdev.github.io/) installed:

```sh
make                    # narcade.prx + EBOOT.PBP
make -f Makefile.iso    # static ELF for the ISO
python3 tools/package_iso.py
```

On Windows, `python tools/build_windows.py` uses a local toolchain in `build/pspdev`
(not included in the repository) and produces `Narcade.iso` and `EBOOT.PBP`.
A GitHub Actions workflow builds the game on every push.

### Tests

The `tools/qa_*.c` files are compiled with a normal desktop GCC against the game code
and check things like walking and driving feel, collisions, traffic, invisible walls
(`qa_invisible_walls_v226.c`) and renderer cost. See the comment at the top of each file.
